# 🏥 Serena — Doctor Appointment Scheduling System

A doctor appointment scheduling system developed as a university project using PHP, MySQL, HTML, and CSS.

## 📌 About the Project

Serena is a web-based application designed to simplify doctor appointment scheduling and management. It allows users to view doctors, select available appointment slots, and manage bookings. Staff can manage appointments, update doctor information, and handle notifications.

## ✨ Features

- 👨‍⚕️ Doctor directory and information management
- 📅 Appointment booking and scheduling
- 🧑 Patient information management
- 🔄 Appointment cancellation and rescheduling
- 🏥 Staff dashboard for appointment management
- 🔔 Notification management

## 🛠️ Technologies Used

- HTML
- CSS
- PHP
- MySQL
- JavaScript

## 🗄️ Database Operations

- **Create:** Add patient and appointment records.
- **Read:** Retrieve doctor, patient, and appointment information.
- **Update:** Modify doctor details and appointment status.
- **Delete:** Manage appointment cancellations.

## ⚙️ Setup and Installation

1. Install XAMPP or another compatible PHP and MySQL environment.
2. Place the project folder in the web server's root directory.
3. Create a MySQL database named `Serena`.
4. Create the required database tables based on the queries in the PHP files.
5. Configure the database connection in `conn.php`.
6. Start Apache and MySQL.
7. Open `Home.html` through your local server.

**Note:** The database schema is not included in the current project files, so the required tables must be created before the application can run correctly.
